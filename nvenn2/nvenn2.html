You can save the diagram in three formats:
  • With 
    Download PNG
    , you will save a bitmap. Please, notice that bitmaps are limited in resolution, and you will not be able to recover a diagram saved in this format.
  • With 
    Download SVG
    , you will save an SVG file. This is a vectorial format which can be edited (e. g., with Inkscape) and rendered at any resolution. This SVG file can be loaded at any time with 
    Load a previous run
    .
  • With 
    Save as web page
    , you will save an SVG file inside an HTML file. The web page downloaded can be open with any browser. It allows users to explore the regions and extract PNG and SVG files with the diagram. This HTML file can be loaded at any time with 
    Load a previous run
    .

Exhaustive mode

(Not recommended) You can use this button to try the exhaustive mode, in which all the possible swaps are examined up to a certain level. In most cases, this algorithm is inferior to the default, and it can make your system unresponsive for a long time. With a depth of one, the minimization steps consider every pairwise swap of regions. With a detph of two, the minimization steps also consider every two-pair swap of regions, and so forth. With a depth equal to the number of regions, all possible combinations will be tested, which may take a very long time. You will get an estimation of the computing time needed for a given depth level.
